MAT 121: DIFFERENTIAL CALCULUS

Comprehensive Study Notes

Differential calculus is the branch of mathematics that studies how quantities change. It introduces the concept of the derivative, which measures the rate of change of a function with respect to one of its variables.

1. Functions and Limits

A function is a rule that assigns each input to exactly one output.

Example: f(x) = x^2 + 2x + 1

1.1 Limit of a Function

The limit of a function describes the value that a function approaches as the input approaches a certain point.

lim x→a f(x) = L

Important: A limit does not necessarily require the function to be defined at the exact point; it only requires values nearby to approach a certain number.

1.2 Continuity

A function is continuous at a point if:

  • f(a) exists
  • lim x→a f(x) exists
  • lim x→a f(x) = f(a)

2. Derivative

The derivative of a function measures the instantaneous rate of change of the function.

f'(x) = lim h→0 [f(x+h) - f(x)]/h

Meaning of the Derivative

  • Slope of the tangent to a curve at a point
  • Rate of change of one variable with respect to another
  • Velocity if the function describes distance with respect to time

3. Standard Rules of Differentiation

FunctionDerivative
f(x) = cf'(x) = 0
f(x) = x^nf'(x) = nx^{n-1}
f(x) = sin xf'(x) = cos x
f(x) = cos xf'(x) = -sin x
f(x) = e^xf'(x) = e^x
f(x) = ln xf'(x) = 1/x

3.1 Constant Rule

If f(x) = c, then f'(x) = 0.

3.2 Constant Multiple Rule

If f(x) = k g(x), then f'(x) = k g'(x).

3.3 Sum and Difference Rule

d/dx [f(x) ± g(x)] = f'(x) ± g'(x)

3.4 Product Rule

If y = uv, then

dy/dx = u dv/dx + v du/dx

3.5 Quotient Rule

If y = u/v, then

dy/dx = (v du/dx - u dv/dx)/v^2

3.6 Chain Rule

If y = f(g(x)), then

dy/dx = f'(g(x)) g'(x)

Example: Differentiate y = (3x^2 + 5)^4
Let u = 3x^2 + 5 and y = u^4
dy/dx = 4u^3 × 6x = 24x(3x^2 + 5)^3

4. Higher Derivatives

The second derivative is the derivative of the first derivative.

f''(x) gives information about curvature and acceleration.

5. Applications of Differentiation

5.1 Tangent and Normal

  • The slope of the tangent at point x = a is f'(a).
  • The normal is perpendicular to the tangent.

5.2 Rates of Change

Derivative is used to calculate how fast a quantity changes over time.

Example: velocity is the derivative of displacement with respect to time.

5.3 Maximum and Minimum Values

To find turning points, solve f'(x) = 0.

  • If f'(x) changes from positive to negative, the point is a local maximum.
  • If it changes from negative to positive, the point is a local minimum.
Example: For f(x) = x^2 - 4x + 3,
f'(x) = 2x - 4 = 0 gives x = 2.
The minimum occurs at x = 2.

6. Implicit Differentiation

When a relation is not explicitly solved for y, we differentiate both sides of the equation with respect to x.

Example: x^2 + y^2 = 25

Differentiate: 2x + 2y dy/dx = 0

Hence dy/dx = -x/y

7. Summary of Important Formulae

  • d/dx(x^n) = nx^{n-1}
  • d/dx(sin x) = cos x
  • d/dx(cos x) = -sin x
  • d/dx(e^x) = e^x
  • d/dx(ln x) = 1/x
  • d/dx(uv) = u v' + v u'
  • d/dx(u/v) = (v u' - u v')/v^2
