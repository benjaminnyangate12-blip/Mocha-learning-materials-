BCS 111: INTRODUCTION TO PROGRAMMING

Detailed Study Notes

This course introduces students to the basic ideas of programming, problem solving, algorithm design, and software development. It builds the logical thinking required to write correct and efficient programs.

1. What is Programming?

Programming is the process of writing instructions that a computer follows to solve a problem or complete a task.

Key idea: A program is a set of clear instructions that tells the computer what to do, in what order, and under what conditions.

1.1 Why Learn Programming?

  • Builds problem-solving ability
  • Supports software and app development
  • Improves logical and structured thinking
  • Useful in automation, science, business, and AI
  • Needed for many modern tech careers

1.2 Basic Computer Components

ComponentPurpose

CPUProcesses instructions and performs calculations

Output devicesShow or produce results

2. Problem Solving and Algorithms

An algorithm is a well-defined sequence of steps used to solve a problem.

Example algorithm to add two numbers:
  1. Start
  2. Read first number
  3. Read second number
  4. Calculate sum
  5. Display result
  6. Stop

Characteristics of a Good Algorithm

  • Clear and precise
  • Finite number of steps
  • Produces output
  • Uses inputs correctly
  • Efficient and understandable

4. Basic Programming Concepts

4.1 Variables

A variable is a named storage location used to hold data while a program runs.

age = 20
name = "Mary"
score = 90.5

4.2 Data Types

TypeExampleUse
Integer25Whole numbers
Float18.5Decimals
String"Hello"Text
BooleantrueLogical values

4.3 Operators

  • Arithmetic: +, -, *, /, %
  • Comparison: ==, !=, >, <, >=, <=
  • Logical: && , || , !
  • Assignment: =, +=, -=

5. Control Structures

5.1 Sequence

Statements are performed in order from top to bottom.

5.2 Selection

Selection allows a program to make decisions based on conditions.

if age >= 18:
    print("Adult")
else:
    print("Minor")

5.3 Iteration

Loops repeat a block of code multiple times.

for i in range(1, 6):
    print(i)

Common loops include for and while loops.

6. Functions

A function is a reusable block of instructions designed to perform a specific task.

def add(a, b):
    return a + b

print(add(5, 3))
Advantages: code reuse, simpler maintenance, easier debugging, and cleaner structure.

7. Arrays and Data Collection

An array stores multiple values of the same type in a single variable.

numbers = [2, 4, 6, 8, 10]
print(numbers[0])

8. Input and Output

Programs often take input from the user and display result via output.

name = input("Enter your name: ")
print("Hello", name)

9. Errors and Debugging

Programming errors can be classified as syntax, logical, or runtime errors.

  • Syntax error: breaks language rules
  • Logical error: runs but gives wrong result
  • Runtime error: happens while executing
Debugging is a necessary skill. It is the process of locating and fixing program errors to ensure a program works correctly.

10. Program Development Procedure

  1. Understand the problem
  2. Design an algorithm
  3. Write the code
  4. Test and debug
  5. Improve and maintain

11. Summary

Programming combines logic, structure, and creativity. It teaches us how to solve problems systematically by converting ideas into instructions a computer can execute.
