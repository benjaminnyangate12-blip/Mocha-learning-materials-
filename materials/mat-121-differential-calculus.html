MAT 121: DIFFERENTIAL CALCULUS

Comprehensive Study Notes

Differential calculus studies how quantities change. It focuses on the derivative, which represents the instantaneous rate of change of a function and is essential in modeling motion, optimization, and growth.

1. Functions and Limits

A function is a rule that assigns each input to exactly one output. Example: f(x) = x^2 + 3x + 2.

1.1 Limit of a Function

The limit of a function describes the value the function approaches as the input approaches a specified number.

lim x→a f(x) = L

A limit may exist even when the function is not defined exactly at the point.

1.2 Continuity

A function is continuous at x = a if:

  • f(a) exists
  • lim x→a f(x) exists
  • lim x→a f(x) = f(a)

2. Derivative

The derivative gives the rate of change of a function and is defined by the limit:

f'(x) = lim h→0 [f(x+h) - f(x)] / h

Interpretations of the derivative include:

  • slope of the tangent to the curve
  • rate of change
  • velocity if distance is a function of time

3.1 Sum and Difference Rule

d/dx [f(x) ± g(x)] = f'(x) ± g'(x)

3.2 Product Rule

If y = uv, then

dy/dx = u dv/dx + v du/dx

3.3 Quotient Rule

If y = u/v, then

dy/dx = (v du/dx - u dv/dx) / v^2

3.4 Chain Rule

If y = f(g(x)), then

dy/dx = f'(g(x)) g'(x)

Example: Differentiate y = (3x^2 + 5)^4
Let u = 3x^2 + 5 so y = u^4.
dy/dx = 4u^3 × 6x = 24x(3x^2 + 5)^3

4. Higher Derivatives

The second derivative is the derivative of the first derivative. It is often used in curve analysis and motion studies.

f''(x) helps identify acceleration and concavity.

5. Applications of Differentiation

5.1 Tangent and Normal

  • The slope of the tangent at x = a is f'(a).
  • The normal is perpendicular to the tangent.

5.2 Rates of Change

Derivatives are used to show how one quantity changes with respect to another.

Example: velocity is the derivative of displacement with respect to time.

5.3 Maxima and Minima

To find turning points, solve f'(x) = 0.

  • Positive to negative change indicates a maximum
  • Negative to positive change indicates a minimum
Example: For f(x) = x^2 - 4x + 3, f'(x) = 2x - 4. Setting this to zero gives x = 2.

6. Implicit Differentiation

If a function is not explicitly written as y = f(x), we differentiate both sides with respect to x.

Example: x^2 + y^2 = 25

Differentiate: 2x + 2y dy/dx = 0

Therefore dy/dx = -x / y

7. Summary of Formulas

  • d/dx(x^n) = n x^{n-1}
  • d/dx(sin x) = cos x
  • d/dx(cos x) = -sin x
  • d/dx(e^x) = e^x
  • d/dx(ln x) = 1/x
  • d/dx(uv) = u v' + v u'
  • d/dx(u/v) = (v u' - u v')/v^2
