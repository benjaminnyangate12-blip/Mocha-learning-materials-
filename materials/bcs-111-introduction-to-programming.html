BCS 111: INTRODUCTION TO PROGRAMMING

Detailed Study Notes

This course introduces students to logic, algorithm design, problem solving, coding, and software development. The objective is to help learners think systematically and transform real-world tasks into executable instructions that a computer can perform.

1. Definition and Scope of Programming

Programming is the process of designing and writing a sequence of instructions that direct a computer to perform a task. It is a combination of logic, mathematical reasoning, and problem-solving.

Programming languages are specifically designed to express operations clearly so they can be interpreted by a machine.

In simple terms: programming is how humans communicate with computers using structured instructions.

1.1 Why Programming is Important

  • It enables software creation for business, education, healthcare, finance, and communication.
  • It supports automation of repetitive tasks.
  • It develops logical and analytical thinking.
  • It is foundational to fields like artificial intelligence, web design, databases, and robotics.
  • It helps people design systems that process data efficiently and accurately.

1.2 Relationship Between Humans and Computers

Computers follow commands precisely and do not think creatively; they depend on well-defined instructions. Therefore, programmers must plan carefully and write error-free logic.

  • Humans define the problem.
  • Programmers design a solution.
  • Computers execute instructions.
  • Output is then checked for correctness.

2. Computer Fundamentals Relevant to Programming

2.1 Data and Information

Data is raw facts, while information is meaningful and processed data. A program often receives data, processes it, and outputs information.

Example: the numbers 70, 75, and 80 are data; their average 75 is information.

2.2 The Data Processing Cycle

Input → Processing → Output → Storage

Programs fit into this cycle by taking input, applying logic, producing output, and sometimes saving data for later use.

3. Problem Solving

Programming begins with problem solving. A programmer must understand the task, examine the requirements, and choose a suitable method for solving it.

3.1 Steps in Problem Solving

  1. Identify the problem clearly.
  2. Define the required input and expected output.
  3. Break the problem into smaller parts.
  4. Design a solution logic.
  5. Implement the solution as code.
  6. Test and debug the program.
  7. Improve or optimize where necessary.

3.2 Real-Life Example

If you want to compute the total cost of items purchased, you must know the relevant inputs, item prices, quantity, tax, and discount before writing code.

4. Algorithms

An algorithm is a step-by-step procedure for solving a problem. It is a plan that allows a computer to do the specified task effectively.

4.1 Characteristics of a Good Algorithm

  • Clear and unambiguous
  • Finite number of steps
  • Has well-defined input and output
  • Produces correct results
  • Should be efficient and easy to understand

4.2 Example Algorithm: Find the Sum of Two Numbers

  1. Start
  2. Read the first number
  3. Read the second number
  4. Add the two numbers
  5. Display the result
  6. Stop

4.3 Pseudocode Example

BEGIN
  READ a
  READ b
  sum ← a + b
  DISPLAY sum
END

6. Programming Languages

A programming language is a formal language used to write instructions for a computer. Different languages are designed for different purposes.

LanguageUse
PythonBeginners, automation, data science, AI
CSystem programming, embedded systems
C++Game and performance-critical software
JavaBusiness applications and Android apps
JavaScriptInteractive websites and web apps

6.1 High-level vs Low-level Languages

  • High-level languages are closer to human languages and easier to learn.
  • Low-level languages interact directly with hardware and are harder for humans to use.

6.2 Translators

Programs are converted into machine-readable form by translators:

  • Compiler: converts the whole program before execution.
  • Interpreter: converts and executes one statement at a time.

7. Variables and Data Types

7.1 Variables

A variable is a named memory location used to store data that may change during program execution.

age = 20
name = "Mary"
score = 85.5

7.2 Rules for Naming Variables

  • Use meaningful names
  • Cannot start with a number
  • Must avoid reserved keywords
  • Should be consistent and readable

7.3 Data Types

Data TypeExamplesUse
Integer5, -2, 0Whole numbers

8. Operators

8.1 Arithmetic Operators

+, -, *, /, %, ++, --

Example: 12 + 7 = 19; 15 % 4 = 3

8.2 Comparison Operators

==, !=, >, <, >=, <=

Used to compare values and test conditions.

8.3 Logical Operators

&&, ||, !

Used to combine conditions in decision making.

8.4 Assignment Operators

=, +=, -=, *=, /=

9. Input and Output

9.1 Input

Input allows the program to receive data while running. This can be from a keyboard, file, sensor, or network.

name = input("Enter your name: ")

9.2 Output

Output displays results to the user or writes them to a file.

print("Hello", name)

9.3 Importance of Input/Output

All useful programs depend on data input and useful output. Without one or the other, a program becomes less practical.

10. Control Structures

Control structures define the flow of execution within a program.

10.1 Sequence

Statements execute one after another in the order they are written.

10.2 Selection

Selection allows the program to choose between alternative actions depending on a condition.

if score >= 50:
    print("Pass")
else:
    print("Fail")

10.3 Repetition (Loops)

Loops are used when a task must repeat multiple times.

for i in range(1, 6):
    print(i)

Loops are useful in managing arrays, running checks, and automating repeated operations.

Types of loops

  • for loop: used when the number of iterations is known
  • while loop: used when the number of iterations depends on a condition

11. Functions and Modular Programming

A function is a named block of code that performs a specific operation. Functions allow programmers to group features and reuse them in different parts of a program.

def add(a, b):
    return a + b

print(add(6, 9))

11.1 Advantages of Functions

  • Promotes code reuse
  • Improves readability
  • Makes debugging easier
  • Helps break complex tasks into smaller tasks
  • Improves maintainability

11.2 Function Components

  • Function name
  • Parameters (optional)
  • Body
  • Return value (optional)

12. Arrays and Lists

An array/list stores multiple values in a single variable. This is important when handling a set of related values like marks, names, or measurements.

numbers = [10, 20, 30, 40]
print(numbers[2])

12.1 Uses of Arrays

  • Store scores in a class
  • Track employee names
  • Process sensor readings
  • Manage inventory records

13. String Processing

Strings are sequences of characters used to represent text. Strings can be manipulated using operations like splitting, joining, slicing, and comparison.

name = "Benjamin"
print(name[0])
print(name[1:5])

13.1 String Operations

  • Concatenation
  • Length calculation
  • Substring extraction
  • Comparison
  • Case conversion

14. Error Handling and Debugging

A program may contain errors that prevent it from working the way it should. Errors must be identified and corrected through testing and debugging.

14.1 Types of Errors

Error TypeDescription
Syntax errorRules of the language are violated
Runtime errorOccurs while the program is running
Logical errorProgram runs but produces wrong output

14.2 Debugging Process

  1. Read the error message
  2. Trace values and variables
  3. Check logical conditions
  4. Test again after each fix

15. Program Development Life Cycle

Programming is not just writing code; it is a full process.

  1. Understand the problem
  2. Plan the algorithm
  3. Write the code
  4. Test and debug
  5. Document and maintain the program

16. Structured Programming Principles

  • Use clear, readable logic
  • Break large tasks into smaller parts
  • Use consistent naming
  • Comment code where necessary
  • Keep functions simple and focused
  • Validate user input

17. Practical Examples

Example 1: Find the Average of Three Numbers

num1 = 10
num2 = 20
num3 = 30
average = (num1 + num2 + num3) / 3
print("Average is", average)

Example 2: Determine if a Number is Even

n = 12
if n % 2 == 0:
    print("Even")
else:
    print("Odd")

Example 3: Multiplication Table

for i in range(1, 11):
    print("5 x", i, "=", 5 * i)

18. Best Practices for Beginners

  • Write small programs before large ones
  • Practice algorithm design daily
  • Review code for clarity and structure
  • Test with sample inputs
  • Learn from errors instead of fearing them

19. Summary

Programming is a discipline that combines logic, creativity, and problem solving. Writing good programs requires clear understanding, strong algorithms, well-chosen data structures, correct syntax, and careful debugging. It is a core skill in all modern technology disciplines.
