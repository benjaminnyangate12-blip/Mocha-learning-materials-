BCS 121: DISCRETE STRUCTURE 1

Detailed Study Notes

Discrete structure is a foundational part of computer science and mathematics. It studies discrete, separate, and countable elements, and provides the mathematical structure used in logic, algorithms, databases, programming, and formal reasoning.

1. Introduction to Discrete Mathematics

Discrete mathematics is the study of structures that are distinct and separate rather than continuous. This means it focuses on elements that can be counted, listed, or logically reasoned about individually.

Unlike continuous mathematics, which deals with real-valued quantities and smooth change, discrete mathematics studies integers, sets, graphs, logic, relations, and finite structures.

1.1 Why Discrete Mathematics is Important

  • It underpins computer science and software engineering.
  • It is essential in algorithm analysis and design.
  • It supports coding logic, database design, and formal specification.
  • It is used in cryptography, networks, and artificial intelligence.
  • It helps in reasoning clearly and proving correctness.

2. Sets

A set is a collection of well-defined objects, called elements or members.

Example: A = {1, 2, 3, 4, 5}

Sets may be finite or infinite. They may contain numbers, letters, objects, or even other sets.

2.1 Types of Sets

Empty setContains no elements
Universal setContains all elements under discussion

2.2 Set Notation

2.3 Equality of Sets

Two sets are equal if they contain exactly the same elements, regardless of order.

{a, b, c} = {c, a, b}

2.4 Subsets

If every element of set A is also an element of set B, then A is a subset of B.

A ⊆ B

Every set is a subset of itself, and the empty set is a subset of every set.

3. Set Operations

3.1 Union

The union of two sets includes all elements in either set.

A ∪ B = {x : x ∈ A or x ∈ B}

3.2 Intersection

The intersection of two sets includes only elements that appear in both sets.

A ∩ B = {x : x ∈ A and x ∈ B}

3.3 Difference

Difference A - B includes elements found in A but not in B.

A - B = {x : x ∈ A and x ∉ B}

3.4 Complement

The complement of a set consists of the elements in the universal set that are not in the set.

A' = U - A

3.5 Examples

Example:
A = {1, 2, 3, 4}
B = {3, 4, 5, 6}
A ∪ B = {1, 2, 3, 4, 5, 6}
A ∩ B = {3, 4}
A - B = {1, 2}

4. Venn Diagrams

Venn diagrams are visual tools used to represent sets and relationships among them. They are useful in solving problems involving unions, intersections, complements, and differences.

In a Venn diagram, each set is shown as a circle inside a universal rectangle.

5. Cartesian Product

The Cartesian product of sets A and B, written A × B, is the set of all ordered pairs (a, b) where a ∈ A and b ∈ B.

Example: If A = {1, 2} and B = {x, y}, then
A × B = {(1, x), (1, y), (2, x), (2, y)}

Cartesian products are important in relations, database tables, and coordinate systems.

6. Relations

A relation is any set of ordered pairs. It shows how elements of one set are associated with elements of another set.

If A and B are sets, then any subset of A × B is a relation from A to B.

6.1 Domain and Codomain

  • Domain: set of all first elements
  • Range: set of all second elements
  • Codomain: target set

6.2 Types of Relations

TypeDefinition
ReflexiveEvery element is related to itself
SymmetricIf a is related to b, then b is related to a
AntisymmetricIf aRb and bRa, then a = b
TransitiveIf aRb and bRc, then aRc

7. Functions

A function is a special type of relation where each element in the domain is associated with exactly one element in the codomain.

f: A → B

Key rule: no input may map to multiple outputs in a valid function.

7.1 One-to-One and Onto Functions

TypeMeaning
One-to-oneDistinct inputs give distinct outputs
OntoEvery output in the codomain is used

7.2 Example

f(x) = 2x + 1 is a function because every x produces one unique result.

8. Logic and Propositions

A proposition is a statement that is either true or false.

Logical SymbolMeaning
∧AND
∨OR
¬NOT
→Implication
↔If and only if

8.1 Truth Tables

Truth tables are used to determine whether compound logical statements are true or false.

If P is “it is raining” and Q is “the ground is wet,” then P → Q means: if it is raining, then the ground is wet.

8.2 Tautology, Contradiction and Contingency

  • Tautology: always true
  • Contradiction: always false
  • Contingency: sometimes true and sometimes false

9. Predicates and Quantifiers

A predicate is a statement that depends on a variable and may become true or false depending on the value assigned.

Common quantifiers:

  • ∀ = for all
  • ∃ = there exists
∀x, x + 1 > x is true for all real numbers x.

10. Counting Principles

Counting is an essential part of discrete mathematics. It is used in probability, algorithm analysis, and combinatorics.

10.1 Inclusion-Exclusion Principle

|A ∪ B| = |A| + |B| - |A ∩ B|

If 25 students like Math and 18 like Science, and 7 like both, then the number that like at least one is 25 + 18 - 7 = 36.

10.2 Product Rule

If there are m ways to do one thing and n ways to do another, then there are m × n ways to do both.

10.3 Permutations and Combinations

  • Permutation: order matters
  • Combination: order does not matter

11. Boolean Algebra

Boolean algebra is used in digital logic circuits. It is based on variables that can be true or false.

12. Graph Theory (Introductory)

A graph is a collection of vertices connected by edges. Graphs are used in road networks, social networks, and computer networks.

ConceptMeaning

PathA sequence of connected vertices

13. Applications in Computing

  • Algorithms and complexity
  • Database design and query logic
  • Formal verification
  • Computer networks
  • Cryptography
  • Programming language theory

14. Mathematical Proof

Proof is used to show that a statement is true beyond doubt. Typical methods include direct proof, proof by contradiction, and induction.

14.1 Mathematical Induction

Induction proves a statement for all natural numbers by showing it works for the first case and then for the next case based on the previous one.

15. Summary

Discrete structure provides the mathematical language for understanding computer logic and computational thinking. It introduces sets, relations, functions, logic, counting, and proof techniques that are fundamental to modern computing and problem solving.
