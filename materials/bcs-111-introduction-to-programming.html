BCS 111: INTRODUCTION TO PROGRAMMING

Detailed Notes and Study Guide

This unit introduces the fundamentals of programming and problem solving. It teaches students how computers process instructions, how to design algorithms, and how to write programs using structured programming concepts.

1. What is Programming?

Programming is the process of creating a sequence of instructions that a computer can follow to solve a problem or perform a task.

Key idea: A program is written to tell the computer what to do, in what order, and under what conditions.

1.1 Why Learn Programming?

  • It develops problem-solving skills.
  • It helps in building software applications.
  • It is used in web development, data analysis, AI, and automation.
  • It improves logical and computational thinking.

2. Problem Solving and Algorithm Development

An algorithm is a step-by-step procedure for solving a problem.

Example algorithm for adding two numbers:
  1. Start
  2. Input first number
  3. Input second number
  4. Compute sum
  5. Display sum
  6. Stop

Characteristics of a Good Algorithm

  • Clear and unambiguous
  • Finite steps
  • Input and output defined
  • Efficient
  • Easy to understand and implement

4. Basic Programming Concepts

4.1 Variables

A variable is a named memory location used to store data.

age = 20
name = "Mary"
score = 90.5

Variables are assigned values that can change during program execution.

5. Control Structures

5.1 Sequence

Instructions are executed one after another in order.

5.2 Selection

Selection allows a program to choose different actions depending on a condition.

if age >= 18:
    print("Adult")
else:
    print("Minor")

5.3 Iteration (Loops)

Loops repeat a block of code multiple times.

for i in range(1, 6):
    print(i)

Common loop types are for loops and while loops.

6. Functions and Modular Programming

A function is a reusable block of code that performs a specific task.

def add(a, b):
    return a + b

print(add(5, 3))
Advantages of functions: code reuse, easier debugging, simpler program structure, and maintainability.

7. Arrays and Data Structures

An array stores multiple values of the same type in one variable.

numbers = [2, 4, 6, 8, 10]
print(numbers[0])

Arrays are useful for storing collections of data such as marks, names, temperatures, or test scores.

8. Input and Output

Input allows the user to provide data, while output displays the result.

name = input("Enter your name: ")
print("Hello", name)

9. Error Handling and Debugging

Programming errors may be of several types:

  • Syntax errors: rules of the language are violated
  • Logical errors: code runs but gives wrong results
  • Runtime errors: occur during execution
Debugging is the process of finding and fixing errors in a program. It is an essential part of software development.

10. Program Development Process

  1. Understand the problem
  2. Design an algorithm
  3. Write program code
  4. Test and debug
  5. Improve and maintain

11. Summary

Programming is the act of creating instructions for computers. It combines logical thinking, problem solving, and mathematical reasoning. A good programmer writes clear code, tests carefully, and designs solutions that are efficient and easy to maintain.
