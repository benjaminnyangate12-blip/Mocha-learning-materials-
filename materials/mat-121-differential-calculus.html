MAT 121: DIFFERENTIAL CALCULUS

Comprehensive Study Notes

Differential calculus is the branch of mathematics that measures change. It answers questions like: How fast is a quantity changing? At what point does a function reach a maximum or minimum? What is the slope of a curve at a given point?

1. Introduction to Calculus

Calculus is the study of continuous change. It provides methods for analyzing motion, growth, decay, optimization, and many other processes in science, engineering, and computer applications.

It has two main branches: differential calculus and integral calculus. Differential calculus focuses on rates of change and slopes, while integral calculus focuses on accumulation and area.

1.1 Why Calculus Matters

  • Physics uses it to describe motion and acceleration.
  • Economics uses it to optimize profit and cost.
  • Engineering uses it in design and control systems.
  • Biology uses it to model population growth.
  • Computer graphics uses it for curves and transformation algorithms.

2. Functions

A function is a rule that assigns each input value to exactly one output value.

Example: f(x) = 3x^2 + 2x - 5

2.1 Domain and Range

  • Domain: all possible input values
  • Range: all possible output values
For f(x) = x^2, the domain is all real numbers and the range is all non-negative real numbers.

3. Limits

A limit describes the value a function approaches as the input gets close to some value.

lim x→a f(x) = L

This means that as x approaches a, f(x) approaches L.

3.1 Why Limits Matter

Limits are the foundation of derivatives. Without limits, calculus would not be possible.

Example: lim x→3 (x^2 - 9)/(x - 3) simplifies by factoring to (x - 3)(x + 3)/(x - 3), leaving x + 3. Then as x→3, the limit is 6.

3.2 One-sided Limits

  • Left-hand limit: as x approaches from below
  • Right-hand limit: as x approaches from above

For a two-sided limit to exist, both one-sided limits must agree.

3.3 Infinite Limits and Vertical Asymptotes

If a function grows without bound near a point, the limit may be infinite. This often indicates a vertical asymptote.

4. Continuity

A function is continuous at x = a if the following hold:

  • f(a) exists
  • lim x→a f(x) exists
  • lim x→a f(x) = f(a)

Many algebraic functions are continuous over their domain, but functions can be discontinuous at certain points.

Discontinuity often occurs when a function is undefined, has a hole, or has an asymptote.

5. Derivative

The derivative of a function measures how the function changes at a point. It gives the slope of the tangent line to the curve at that point.

f'(x) = lim h→0 [f(x+h)-f(x)]/h

5.1 Different Notations

The derivative can be written in several ways:

  • f'(x)
  • dy/dx
  • D[f(x)]

5.2 Geometric Meaning

The derivative at a point is the slope of the tangent to the curve at that point. This helps understand how the graph rises or falls.

5.3 Physical Meaning

If a function gives displacement over time, then the derivative gives velocity. If velocity changes, the derivative gives acceleration.

6. Differentiation Rules

6.1 Constant Rule

If f(x) = c, then f'(x) = 0.

6.2 Power Rule

If f(x) = x^n, then f'(x) = n x^{n-1}.

f(x) = x^5 → f'(x) = 5x^4

6.3 Constant Multiple Rule

d/dx [k f(x)] = k f'(x)

6.4 Sum and Difference Rule

d/dx [f(x) ± g(x)] = f'(x) ± g'(x)

6.5 Product Rule

If y = u v, then:

dy/dx = u dv/dx + v du/dx

Example: Differentiate y = x^2 sin x.
Let u = x^2 and v = sin x.
dy/dx = x^2 cos x + 2x sin x

6.6 Quotient Rule

If y = u/v, then:

dy/dx = (v du/dx - u dv/dx) / v^2

6.7 Chain Rule

If y = f(g(x)), then:

dy/dx = f'(g(x)) g'(x)

Example: Differentiate y = (3x + 2)^4.
Let u = 3x + 2, so y = u^4.
dy/dx = 4u^3 × 3 = 12(3x + 2)^3

9. Higher Order Derivatives

The second derivative is the derivative of the first derivative and is written as f''(x).

Higher derivatives are used in:

  • acceleration
  • curvature
  • optimization
  • motion analysis
If s(t) gives displacement, then s'(t) gives velocity and s''(t) gives acceleration.

10. Tangent and Normal Lines

10.1 Tangent Line

The tangent line to a curve at a point has slope f'(a).

The equation can be written as:

y - f(a) = f'(a)(x - a)

10.2 Normal Line

The normal line is perpendicular to the tangent line. If the tangent slope is m, then the normal slope is -1/m (provided m ≠ 0).

11. Applications of Differentiation

11.1 Rates of Change

Derivatives describe how fast quantities change with respect to time or another variable. They are used in velocity, acceleration, population growth, and fluid movement.

11.2 Increasing and Decreasing Functions

  • If f'(x) > 0, the function is increasing.
  • If f'(x) < 0, the function is decreasing.

11.3 Critical Points

Critical points occur where f'(x) = 0 or f'(x) is undefined. These may represent maxima, minima, or saddle-like behavior.

11.4 Maximum and Minimum Values

To find extrema:

  1. Differentiate the function
  2. Solve f'(x) = 0
  3. Use a sign chart or second derivative test
For f(x) = x^2 - 6x + 8, f'(x) = 2x - 6 = 0 gives x = 3. This is a minimum value because the parabola opens upward.

11.5 Second Derivative Test

  • If f''(x) > 0 at a critical point, then it is a local minimum.
  • If f''(x) < 0, then it is a local maximum.

12. Implicit Differentiation

Implicit differentiation is used when the relationship between variables is not written explicitly as y = f(x).

Example: x^2 + y^2 = 25

Differentiate both sides:

2x + 2y dy/dx = 0

dy/dx = -x / y

13. Logarithmic Differentiation

Useful for functions where the variable appears in both the base and exponent or when complicated products/quotients occur. Take natural logs before differentiating.

Example: y = x^x

Take logs: ln y = x ln x

Differentiate: y'/y = ln x + 1

y' = x^x (ln x + 1)

14. Applications in Optimization

Optimization problems involve finding the maximum or minimum value of a function under given conditions.

Common examples include:

  • minimum cost
  • maximum area
  • greatest profit
  • minimum material use
In optimization, the derivative helps identify the best possible value under constraints.

15. Summary of Common Derivatives

  • d/dx (x^n) = n x^{n-1}
  • d/dx (sin x) = cos x
  • d/dx (cos x) = -sin x
  • d/dx (tan x) = sec^2 x
  • d/dx (e^x) = e^x
  • d/dx (ln x) = 1/x
  • d/dx (uv) = u v' + v u'
  • d/dx (u/v) = (v u' - u v')/v^2
