BCS 121: DISCRETE STRUCTURE 1

Detailed Study Notes

Discrete structures are the mathematical foundations of computer science. They deal with distinct, countable objects and provide the structure behind logic, algorithms, and data representation in computing.

1. Introduction to Discrete Mathematics

Discrete mathematics focuses on finite or countable sets and structures. Unlike continuous mathematics, it studies items that are separate and distinct.

Why it matters: It is essential in logic, algorithm design, databases, networking, security, and digital systems.

2. Sets

A set is a well-defined collection of objects known as elements.

Example: A = {1, 2, 3, 4, 5}

2.1 Set Notation

2.2 Types of Sets

  • Finite set
  • Infinite set
  • Universal set
  • Empty set

3. Set Operations

3.1 Union

A ∪ B contains all elements found in either set.

A ∪ B = {x: x ∈ A or x ∈ B}

3.2 Intersection

A ∩ B contains elements common to both sets.

A ∩ B = {x: x ∈ A and x ∈ B}

3.3 Difference

A - B consists of elements in A that are not in B.

3.4 Complement

The complement of a set contains all elements in the universal set not in that set.

Example:
A = {1,2,3,4}
B = {3,4,5}
A ∪ B = {1,2,3,4,5}
A ∩ B = {3,4}

4. Venn Diagrams

Venn diagrams are used to visualize relationships between sets and solve set problems quickly.

5. Relations

A relation is a connection between elements of one set and elements of another set.

If A and B are sets, then a relation is a subset of A × B.

Example: If A = {1,2} and B = {a,b}, then A × B includes pairs like (1,a) and (2,b).

6. Functions

A function is a special relation in which every input has exactly one output.

f: A → B

Rule: each element of the domain must map to one and only one element in the codomain.

Types of Functions

TypeDescription
One-to-oneDifferent inputs give different outputs
OntoEvery output in the codomain is used
InjectiveOne-to-one function
SurjectiveOnto function

7. Logic and Propositions

A proposition is a statement that is either true or false.

SymbolMeaning
∧AND
∨OR
¬NOT
→Implies
↔If and only if
Example: If P is “It is raining” and Q is “The ground is wet,” then P → Q means “If it is raining, then the ground is wet.”

8. Counting Principles

Counting is essential in probability, data analysis, and algorithm design.

8.1 Inclusion-Exclusion Principle

|A ∪ B| = |A| + |B| - |A ∩ B|

Example: If 20 students like Math and 15 like Physics, and 8 like both, then the number who like at least one is 20 + 15 - 8 = 27.

9. Boolean Algebra

Boolean algebra is used in logic circuits and computer design.

  • A ∧ A = A
  • A ∨ A = A
  • A ∧ ¬A = False
  • A ∨ ¬A = True

10. Summary

Discrete structures provide the mathematical language for reasoning about computers and algorithms. By understanding sets, functions, logic, and counting, students can analyze computational processes with precision.
