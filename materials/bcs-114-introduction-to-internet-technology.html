MODULE 1: INTRODUCTION TO COMPUTERS AND TECHNOLOGY

1.1 What is a Computer?

A computer is an electronic device that accepts data as input, processes it according to a set of instructions, stores it, and produces meaningful information as output.

Key Characteristics:

  • Speed – processes millions of instructions per second
  • Accuracy – produces accurate results when correctly instructed
  • Storage – stores large amounts of data
  • Diligence – works continuously without fatigue
  • Versatility – performs many different tasks
  • Automation – operates with minimal human intervention

1.2 Data and Information

Term Definition Example
Data Raw and unprocessed facts 25, 30, 45
Information Processed and meaningful data Average = 33.3

1.4 Generations of Computers

Generation Period Technology Example
First 1940–1956 Vacuum tubes ENIAC, UNIVAC
Second 1956–1963 Transistors IBM 1401
Third 1964–1971 Integrated circuits IBM System/360
Fourth 1971–Present Microprocessors Personal computers
Fifth Present–Future Artificial intelligence and quantum computing AI systems

1.5 Classification of Computers

By Size and Power:

  • Supercomputers – used for scientific research and weather forecasting
  • Mainframes – used by large organisations for bulk data processing
  • Minicomputers – medium-sized computers and servers
  • Microcomputers – desktop computers, laptops, tablets and smartphones

By Purpose:

  • General-purpose computers – used for many different tasks
  • Special-purpose computers – designed for a specific task, such as ATMs and GPS devices

MODULE 3: INTRODUCTION TO THE INTERNET

3.1 Definition of the Internet

The Internet is a global network of interconnected computer networks that communicate using the TCP/IP protocol suite. It is commonly referred to as the network of networks.

3.2 Brief History of the Internet

Year Milestone
1969 ARPANET was created
1971 The first email was sent by Ray Tomlinson
1983 TCP/IP became the standard communication protocol
1989 Tim Berners-Lee proposed the World Wide Web
1991 The World Wide Web became publicly available
1990s Commercialisation and rapid growth of the Internet
2000s Growth of broadband, social media and mobile Internet

3.3 Requirements for an Internet Connection

  1. Computer, smartphone or tablet
  2. Network interface card
  3. Transmission medium, such as cable, fibre or radio waves
  4. Internet Service Provider
  5. Modem or router
  6. Network protocols, especially TCP/IP
  7. Web browser or other Internet software

A protocol is a set of rules that controls how data is transmitted and received across a network.

4.3 Common Internet Protocols

Protocol Full Name Purpose
HTTP HyperText Transfer Protocol Transfers web pages
HTTPS HyperText Transfer Protocol Secure Secure web communication
FTP File Transfer Protocol Transfers files

POP3 Post Office Protocol version 3 Downloads email messages

TCP Transmission Control Protocol Provides reliable data delivery
UDP User Datagram Protocol Provides fast but less reliable delivery

4.4 IP Addressing

An IP address is a unique numerical identifier assigned to a device connected to a network.

IPv4: A 32-bit address such as 192.168.1.1.

IPv6: A 128-bit address such as 2001:0db8:85a3::8a2e:0370:7334.

MODULE 5: WORLD WIDE WEB AND WEB TECHNOLOGIES

5.1 The World Wide Web

The World Wide Web is a system of interconnected documents and resources accessed through the Internet using web browsers. It was invented by Tim Berners-Lee in 1989.

  • Internet – the infrastructure and network
  • WWW – a service that operates on the Internet

MODULE 6: INTERNET SERVICES AND APPLICATIONS

6.1 Email Services

Email is an electronic messaging system that allows users to send and receive text messages over the Internet.

Email Protocols:

  • SMTP – used for sending email
  • POP3 – used for retrieving email (deletes from server)
  • IMAP – used for retrieving email (keeps on server)

6.2 File Transfer Protocol (FTP)

FTP is used to transfer files between computers over a network. It supports uploading and downloading files.

6.3 Streaming Services

Streaming allows users to watch or listen to content in real-time without downloading the entire file.

  • Video streaming – YouTube, Netflix, Vimeo
  • Audio streaming – Spotify, Apple Music, SoundCloud

6.4 Cloud Computing Services

Cloud computing provides on-demand access to computing resources over the Internet.

  • SaaS – Software as a Service (e.g., Google Workspace)
  • PaaS – Platform as a Service (e.g., Heroku)
  • IaaS – Infrastructure as a Service (e.g., AWS)

MODULE 8: INTERNET SECURITY

8.1 Common Internet Threats

Threat Description
Malware Malicious software designed to harm systems
Phishing Fraudulent emails or websites to steal information
Ransomware Software that encrypts files and demands payment
DoS Attack Denial of Service – overwhelming a server with traffic
Man-in-the-Middle Intercepting data between sender and receiver

8.2 Security Best Practices

  • Use strong, unique passwords
  • Enable two-factor authentication (2FA)
  • Keep software and operating systems updated
  • Use antivirus and firewall protection
  • Do not open suspicious email attachments
  • Verify website security (look for HTTPS and padlock)
  • Back up important data regularly
  • Be cautious with personal information online

8.3 Encryption

Encryption is the process of converting data into a code to prevent unauthorised access.

  • SSL/TLS – encrypts web traffic (HTTPS)
  • End-to-end encryption – protects messages from being read by anyone except sender and recipient

MODULE 9: EMERGING TECHNOLOGIES

9.1 Artificial Intelligence (AI)

AI refers to computer systems designed to perform tasks that typically require human intelligence, such as learning and reasoning.

9.2 Internet of Things (IoT)

The IoT is a network of physical devices, vehicles, appliances and other objects embedded with sensors and software to connect and exchange data over the Internet.

Examples:

  • Smart homes – thermostats, lights, security systems
  • Wearables – smartwatches, fitness trackers
  • Smart cities – traffic systems, utilities management
  • Industrial IoT – sensors in manufacturing and production

9.3 5G Technology

5G is the fifth generation of cellular network technology, offering significantly faster speeds and lower latency than 4G LTE.

Advantages:

  • Faster data speeds
  • Lower latency (reduced delay)
  • Support for more connected devices
  • Enables real-time applications

9.4 Blockchain and Cryptocurrency

Blockchain is a distributed ledger technology that records transactions across multiple computers in a secure and transparent manner.

Cryptocurrency (e.g., Bitcoin, Ethereum) is digital currency secured by blockchain technology.
