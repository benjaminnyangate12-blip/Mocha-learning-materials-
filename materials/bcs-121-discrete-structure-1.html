BCS 121: DISCRETE STRUCTURE 1

Detailed Study Notes

Discrete structure is the mathematical foundation of computer science. It deals with countable, distinct, and separable objects, which are essential in logic, algorithms, data structures, and formal reasoning.

1. Introduction to Discrete Mathematics

Discrete mathematics is the study of mathematical structures that are fundamentally discrete rather than continuous. It is critical in computing because digital systems work with finite, distinct values.

Applications in Computing

  • Logic design
  • Algorithms and complexity
  • Databases
  • Programming language theory
  • Computer networks and security

2. Sets

A set is a well-defined collection of objects called elements.

Example: A = {1, 2, 3, 4, 5}

2.1 Set Notation

NotationMeaning
{ }Empty set
∈Element of
∉Not an element of
⊆Subset
∪Union
∩Intersection

2.2 Types of Sets

  • Finite set: has a limited number of elements
  • Infinite set: has unlimited elements
  • Universal set: contains all elements under discussion
  • Empty set: contains no elements

3. Set Operations

3.1 Union

The union of two sets contains all elements from both sets.

A ∪ B = {x : x ∈ A or x ∈ B}

3.2 Intersection

The intersection contains the elements common to both sets.

A ∩ B = {x : x ∈ A and x ∈ B}

3.3 Difference

The difference A - B contains elements in A but not in B.

3.4 Complement

The complement of a set contains all elements in the universal set that are not in the set.

Example:
A = {1, 2, 3, 4}
B = {3, 4, 5}
A ∪ B = {1, 2, 3, 4, 5}
A ∩ B = {3, 4}

4. Venn Diagrams

Venn diagrams are used to visualize relationships between sets. They are especially useful in solving logic and counting problems.

5. Relations

A relation is a rule that associates elements of one set with elements of another set.

If A and B are sets, then a relation from A to B is a subset of A × B.

Example: If A = {1, 2} and B = {a, b}, then A × B contains ordered pairs such as (1, a) and (2, b).

5.1 Types of Relations

  • Reflexive
  • Symmetric
  • Antisymmetric
  • Transitive

6. Functions

A function is a special type of relation in which each input has exactly one output.

f: A → B

Important: A function must assign exactly one value in the codomain to each element in the domain.

Types of Functions

TypeDescription
One-to-oneDistinct inputs give distinct outputs
OntoEvery element of the codomain is used
InjectiveOne-to-one function
SurjectiveOnto function

7. Logic and Propositions

A proposition is a statement that is either true or false.

Logical connectiveMeaning
∧AND
∨OR
¬NOT
→Implies
↔If and only if

Example

P: It is raining

Q: The ground is wet

P → Q means: if it is raining, then the ground is wet.

8. Counting Principles

Counting is essential in probability, combinatorics, and algorithm analysis.

8.1 Inclusion-Exclusion Principle

|A ∪ B| = |A| + |B| - |A ∩ B|

Example: If 20 students like Maths and 15 like Physics, and 8 like both, then the total number who like at least one subject is 20 + 15 - 8 = 27.

9. Boolean Algebra

Boolean algebra is the algebra of logic used in digital computers and circuit design.

  • A ∧ A = A
  • A ∨ A = A
  • A ∧ ¬A = False
  • A ∨ ¬A = True

10. Summary

Discrete structure gives the mathematical language used to reason about algorithms, logic, and computation. By understanding sets, relations, functions, logic, and counting principles, students can solve many computational problems systematically.
